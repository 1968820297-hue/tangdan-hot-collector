<h1 align="center">汤淡采集</h1>
<p align="center">热点宝达人分析 · 抖音作品采集 · 私聊灵感入库 · 视频逐字稿</p>

把浏览抖音时发现的达人、作品和私聊转发，整理到自己的飞书多维表格。汤淡采集是一款本地运行的 Chrome 扩展，适合 IP 操盘手、编导和内容创作者建立选题库、竞品作品库与文案研究资料库。

当前版本：**0.3.9**。不需要安装 Node.js，也不需要编译；下载后即可在 Chrome 加载。

[下载 ZIP](https://github.com/1968820297-hue/tangdan-hot-collector/archive/refs/heads/main.zip) · [使用教程](使用教程.md) · [GitHub 仓库](https://github.com/1968820297-hue/tangdan-hot-collector)

## 关于汤淡

你好，我是汤淡。这个仓库用来整理和分享「汤淡采集」及其使用方法，希望让达人研究、作品收集和视频文案整理更方便。

## 可以用来做什么

- **IP 选题研究**：记录对标达人信息、近 30 天作品表现和粉丝画像，辅助判断账号方向。
- **竞品作品库**：按发布日期、点赞门槛筛选作品，保留标题、互动数据、链接和可获取的热评。
- **私聊灵感收集**：把看到的视频转发到指定抖音会话，由专用监控页识别新分享并写入飞书。
- **口播文案研究**：按需把视频语音转成逐字稿，和作品信息放在同一条记录里，方便拆解开头、结构和表达。

## 功能一览

| 功能 | 输入 / 使用位置 | 结果 |
| --- | --- | --- |
| 达人信息采集 | 热点宝达人详情页、抖音达人主页 | 基础信息、近 30 天平均互动、粉丝画像写入指定数据表 |
| 主页作品采集 | 抖音达人主页 | 作品写入同一 Base 的「竞品达人视频数据」表 |
| 单条作品采集 | 抖音视频详情页 | 当前作品入库，按视频链接查重更新 |
| 作品筛选 | 主页作品同步面板 | 日期区间、最低点赞数、按点赞或评论排序 |
| 热评采集 | 作品同步时勾选 | 尝试读取前 3 条热评；结果受平台返回数据影响 |
| 私聊自动监控 | 指定会话 + 本人的抖音昵称 | 识别本人新转发的视频，标记收集人并入库 |
| 自动逐字稿 | 私聊、手动作品同步或飞书表内勾选 | 调用阿里云百炼，回写逐字稿及任务状态 |
| 字段与去重 | 飞书同步时 | 按配置补齐缺失字段；达人按 ID、作品按链接更新 |

达人数据写入设置页指定的 `table_id`；作品写入同一 Base 下的「竞品达人视频数据」表，缺少该表时会自动创建。

## 安装：下载 ZIP → 解压 → Chrome 加载

1. 在本仓库点击 **Code → Download ZIP**，下载后解压。
2. 在 Chrome 地址栏输入 `chrome://extensions/`。
3. 打开右上角「开发者模式」，点击「加载已解压的扩展程序」。
4. 选择包含 `manifest.json` 的目录。不要选择 ZIP，也不要选择它外面的父目录。
5. 在 Chrome 扩展菜单中固定「汤淡采集」，然后刷新已经打开的抖音 / 热点宝页面。

更新时，用新版本替换原扩展目录文件，再在 `chrome://extensions/` 点击扩展的重新加载按钮。扩展配置保存在 Chrome 本地存储中，替换文件不会主动重置配置；重新安装或更换目录时请重新确认设置。

## 首次配置飞书

准备一张自己可编辑的飞书多维表格，并在其中选择一张接收**达人信息**的数据表。

1. 在目标多维表格的「自定义插件 / 获取授权码」入口获取自己的 `pt-...` 授权码。
2. 点击插件图标 →「飞书与逐字稿设置」，选择「多维表格授权码（推荐）」。
3. 填写授权码、收集人名称，以及 `app_token / base_token` 和 `table_id`。
4. 也可以粘贴类似 `https://xxx.feishu.cn/base/bascnxxxx?table=tblxxxx` 的链接，点击「从 URL 填入」。
5. 点击「测试连接」，读到字段数量后，再点击「保存设置」。**测试连接不会保存设置，也不代表已完成写入验证。**

首次配置没有预填任何目标表。默认收集人为「汤淡」，请按自己的使用身份确认。

`/wiki/...` 链接中的 token 是知识库节点标识，不能直接当作 `base_token` 使用；需要填写底层多维表格的真实 token。最直接的方式是获取该多维表格的 `/base/...` 链接。

也支持「飞书开放平台 App ID / Secret」模式，需要应用具备多维表格读写权限，并获得目标表格访问与编辑权限。操作细节见 [使用教程](使用教程.md)。

## 四条使用路径

### 1. 研究一个达人

登录 [抖音热点宝](https://douhot.douyin.com/)，打开达人详情页，点击右下角「同步到飞书」。也可以打开抖音达人主页，点击插件中的「提取并同步飞书」，跳转到热点宝后采集。

「输入链接提取」支持完整主页 / 热点宝详情链接，也会尝试解析分享文本中的抖音短链。短链需能跳转或从响应中识别公开达人 ID；不是任意口令都能解析，`/user/self` 也不是可用的公开达人 ID。

### 2. 建立竞品作品库

打开达人抖音主页 →「同步主页作品」或「筛选作品同步」→ 选择日期、最低点赞和排序 → 按需勾选热评 / 逐字稿 → 同步。

只需要一条视频时，打开视频详情页，点击「同步当前作品」。回到飞书的「竞品达人视频数据」查看结果；重复同步同一链接会更新原记录。

### 3. 把私聊当作灵感收集入口

在设置页填写「目标私聊名称」和「自己的抖音昵称」，二者必须与抖音页面显示一致。启用监控、保存设置，并打开专用监控页；确认登录抖音、能够进入目标会话。

首次运行会将当前可见消息建立为历史基线，随后处理符合条件的新分享，**不用于批量补采历史聊天**。保持 Chrome 和专用监控页运行，再用填写的本人账号向目标会话转发视频。监控和启动时自动打开监控页默认关闭。

### 4. 给作品补逐字稿

先在设置页填写阿里云百炼 DashScope API Key。插件使用 `paraformer-v2`，会向阿里云提交视频文件地址，并产生相应服务调用费用。

- 私聊自动转写：开启「新监控视频入库后自动转逐字稿」。
- 手动同步转写：在本次作品同步时勾选转写选项。
- 已入库作品转写：在飞书表内勾选「转逐字稿」，插件约每分钟检查一次请求。

完成后查看「直接转逐字稿」和「逐字稿状态」列。电脑休眠、Chrome 关闭或视频源不可访问时，处理可能延后或失败；自动识别结果需要人工复核。

## 数据与运行范围

- 达人信息包括名称、抖音号、粉丝 / 获赞 / 作品总数、签名、标签、近 30 天平均互动及粉丝画像；接口没有返回的内容可能留空。
- 作品信息包括标题、作者、收集人、封面地址、互动数、热评、时长、发布日期、视频链接和逐字稿状态。**本项目不提供视频文件批量下载功能。**
- 采集依赖当前浏览器登录态、页面结构、接口返回和账号访问权限，不能保证获得全部作品、完整画像或每条热评。
- 凭据保存在本机 Chrome 扩展存储中；使用时会发送到对应的飞书或阿里云 API。不要将授权码、App Secret、API Key 写入源码或提交到仓库。
- 扩展申请的 `debugger` 权限用于私聊页面自动点击 / 键盘交互，`alarms` 用于后台任务调度。监控是本机浏览器流程，并非独立云端常驻服务。
- 仓库包含功能实现与使用说明；真实采集、飞书写入和阿里云转写仍需使用自己的账号与配置验证，不代表对所有账号或平台版本均已完成联调。

## 常见问题

| 问题 | 检查方式 |
| --- | --- |
| 加载失败 | 确认已解压，选择的目录内直接包含 `manifest.json` |
| 页面没有采集面板 | 确认网址受支持，安装 / 更新后刷新页面 |
| 测试连接成功但同步失败 | 测试仅检查读取字段；再确认编辑权限、字段类型和目标表设置 |
| 短链无法识别 | 在浏览器打开短链，取得公开达人主页完整链接后重试 |
| 监控没有入库 | 核对会话名、本人昵称、登录态和监控状态；建立基线后再新转发一条视频 |
| 热评为空或数量不足 | 平台可能未返回内容；没有点赞数时会按当前展示顺序取前 3 条 |
| 逐字稿没有生成 | 检查 API Key、任务勾选、视频源和「逐字稿状态」，保持 Chrome 运行 |
| 更新后还显示旧昵称 | 在设置页修改并保存；旧配置独立于扩展文件 |
| 标签列类型不匹配 | 在飞书中将已有字段调整为多选；插件不会强制转换已有列 |

更多步骤与字段说明见 [使用教程](使用教程.md)。

## 文件结构

```text
├── manifest.json                 # Chrome Manifest V3 配置
├── background.js                 # 飞书同步、私聊队列与逐字稿后台任务
├── douhot-extractor.user.js       # 热点宝 / 抖音页面采集与浮动面板
├── chat-monitor.js               # 专用监控页的消息识别
├── popup.html / popup.js         # 工具栏弹窗
├── options.html / options.js     # 飞书、监控与转写设置
├── icons/                        # 蓝底白色「淡」字图标
├── 使用教程.md                # 完整操作说明
├── 整合版安装说明.md              # 整合版安装补充
└── 技术复盘/                      # 架构图与技术复盘文档
```

开发调试可直接编辑上述静态文件，再在 Chrome 扩展管理页重新加载。`douhot-extractor.user.js` 另保留 Tampermonkey / Violentmonkey 用法：在热点宝详情页执行 `window.douhotCreatorExtractor.run()` 提取数据，通过 `window.douhotCreatorExtractor.lastResult` 查看最近结果。完整的飞书同步、监控与转写流程请使用 Chrome 扩展。
